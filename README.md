# WSO2 Cloud samples

Samples that the WSO2 Cloud console agent can deploy for you. Each folder is one sample. Its `AGENTS.md` holds the deploy steps that the agent follows.

| Sample | Folder |
| --- | --- |
| Order Processing API | [`order-processing-api`](order-processing-api) |

In the WSO2 Cloud console, open the agent panel and type `/sample`, then pick a sample.
