# Order Processing API

A REST API that accepts orders and returns their status. The backend is a public echo service: every call returns the request it got. Use this sample to try the API Platform on WSO2 Cloud.

To deploy it, type `/sample Order Processing API` in the agent panel of the WSO2 Cloud console. The agent follows [`AGENTS.md`](AGENTS.md).

`openapi.yaml` describes the API.
